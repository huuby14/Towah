# Joshua Jireh S. Macavinta — Portfolio

A responsive personal portfolio for an aspiring front-end developer and Information Technology student. Built with plain HTML, CSS, and JavaScript.

## Run locally

Open `index.html` in a browser. No build step or package installation is required.

## Personalize

Update contact links, phone number, and academic year in `script.js`. Replace `images/joshua-profile.jpg` to change the profile photo.
